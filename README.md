# Gonogo Uplinks

Uplinks extend the [Gonogo](https://github.com/ksp-gonogo/gonogo) mission control
app for Kerbal Space Program. Each one is a KSP plugin plus a small web client,
built and released on its own, and loaded by the app at runtime.

## Adding one

Copy `uplinks/example/`, rename it, and replace the payload. It is the smallest
Uplink that is still a real one: one channel, one widget, no third-party mod. CI
picks up any directory under `uplinks/`, so there is no config to edit.

See [docs/building.md](docs/building.md) for the build, and what you need
installed first.
